{% comment %} Collapsible box, opening half -- pair with details_close.html. Usage (in a post or page's Markdown): {% include details_open.html summary="A short **summary**" %} Markdown for the body: headings, lists, code, footnotes. {% include details_close.html %} Parameters: - summary (required) : the always-visible line; inline Markdown, links too. Use single quotes around it if it contains a ". - title (optional) : a heading run in, bold, at the start of the summary, so screen readers can jump between boxes. Its id is the slugified title, for /page/#title links. - heading (optional) : the title's tag, "h3" by default. Set it one level below the heading the box sits under. - open (optional) : true to start expanded. Closed by default. Only the chevron toggles the box. The summary text sits outside it, so it can hold links without nesting them inside a button (WCAG 4.1.2); the chevron is a native , named "Details" and described by the title, or by the summary text when there is no title. This emits raw HTML into the Markdown before kramdown runs. markdown="1" tells kramdown to convert the body in the same pass as the rest of the post, so footnotes, reference links and heading ids work inside the box.
